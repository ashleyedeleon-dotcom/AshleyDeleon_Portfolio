Brief

Project Overview

Project NameRTXHUB

Project TypeWeb Application Design & AI Integration

Target AudienceAir passengers, particularly first-time flyers

Problem Statement

Frequent flight delays, unexpected itinerary changes, and complex airport processes create high levels of anxiety and uncertainty for travelers, especially those navigating air travel for the first time. Current flight status applications focus primarily on raw data — such as flight numbers, technical aircraft information, and general alerts — without tailoring information to the individual passenger's journey or offering real-time, actionable support.

Solution

RTXHUB bridges the gap between raw aviation data and passenger needs by combining real-time flight tracking with an AI-powered conversational companion. Designed as a cohesive web application, the solution prioritizes personalization, automated support, and accessibility resources to ensure travelers stay informed and confident throughout every phase of their flight.

Process

From concept directly into a high-fidelity Figma screen

Key Features & Capabilities

AI Companion Bot

An integrated LLM-driven assistant providing real-time, conversational answers to passenger queries and offering step-by-step guidance during transit.

Personalized Flight Dashboard

A user-centered interface that centralizes flight tracking, schedule alerts, aircraft details, and historical flight data in one accessible place.

Automated Support & Accessibility Resources

Tailored features designed to assist underrepresented or first-time travelers with navigation tools, clear notifications, and customized assistance.

Full-Stack Technical Integration

A functional prototype built using Python and Flask on the back end to handle data logic and LLM interactions, paired with a front-end UI constructed in HTML and CSS.

Design & User Experience Iterations

AI Companion & Layout Sprint

Mapped user flows in Figma to seamlessly integrate an LLM chatbot into the main dashboard, ensuring immediate assistance without cluttering core flight metrics.

Navigation Bar & Wayfinding Strategy

Iterated on standard mobile navigation patterns to design a streamlined bottom nav bar. Prioritized high-utility touchpoints — Flight Search, Active Itinerary, AI Assistant, and Accessibility Options — to reduce cognitive load during high-stress travel moments.

Outcome

RTXHUB successfully transformed raw aviation data into an intuitive, user-centered digital companion. By pairing real-time flight tracking with an accessible navigation structure and conversational AI assistance, the project delivered a functional prototype that simplifies transit, reduces travel anxiety, and empowers passengers with clear, personalized guidance.
