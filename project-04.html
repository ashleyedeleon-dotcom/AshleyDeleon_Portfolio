Project Overview

Project NameFinancial Literacy Mobile App (2-Day Sprint Prototype)

Project TypeRapid UI/UX Design Sprint (48-Hour Concept Prototype)

Target AudienceYoung adults and first-time earners

Sprint Note This project represents an exploratory, high-level proof of concept designed under time constraints. It focuses on rapid UI/UX ideation rather than a fully fleshed-out product ecosystem.

Problem Statement

Young adults and first-time earners often find traditional financial and banking applications overwhelming, rigid, and filled with dense jargon. Without accessible guidance or intuitive visualization tools, many struggle to establish healthy savings habits, track spending, or build foundational financial confidence.

Solution

A lightweight, mobile-first financial companion that breaks down personal finance into actionable steps. By combining clear visual progress trackers, bite-sized learning modules, and simplified account dashboards, the app helps users understand where their money goes and build long-term financial health without cognitive overload.

Process

Key Features & Capabilities

Interactive Budgeting Dashboard (Concept)

A high-level visual summary of income and expenses designed to test scannable layout structures.

Bite-Sized Literacy Modules

Concept screens for gamified, micro-learning topics like credit building and compound interest.

Rapid Goal Tracking

Dynamic progress bars mapped out to illustrate simple savings milestone interactions.

Streamlined Onboarding Flow

A lightweight, 3-step setup concept designed to demonstrate fast user acquisition.

Rapid Design Sprint Execution (Under 48 Hours)

High-Speed Concept Mapping

Executed rapid low-fidelity sketching sessions to identify core user pain points and define key prototype screens within hours.

Essential UX/UI Architecture

Prioritized a temporary, high-utility bottom navigation bar to keep the prototype navigable and focused on core interactions.

Lightweight Visual Styling

Applied a fast visual system using clear typography, high-contrast cards, and simple color coding for quick data scannability.

Fast-Paced Figma Prototyping

Built interactive component variants and basic screen transitions in Figma to deliver a functional, presentable proof-of-concept before the 2-day deadline.

Outcome

Delivered a functional, high-level Figma prototype within a 2-day constraint. While designed as a temporary concept, the sprint successfully demonstrated how rapid design thinking and clean visual hierarchy can make personal finance feel simple, modern, and intuitive.
